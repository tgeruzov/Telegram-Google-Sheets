**Простая система диспетчеризации заявок через Telegram и Google Таблицы.**

Этот проект родился из реальной боли. Я работал выездным инженером (обслуживание IT-оборудования на автобусах). Диспетчер закидывал заявки в Excel/Google Таблицу, а мне приходилось постоянно её обновлять с телефона, зумить ячейки и пытаться попасть пальцем в выпадающий список, чтобы сменить статус. Это было неудобно.

Так появился этот бот. Диспетчер работает в привычной Таблице, инженер - в удобном чате Telegram.

## 🔥 Возможности

* **Мгновенные уведомления:** Как только в таблице появляется статус `новая`, бот присылает уведомление инженеру.
* **Интерактивные кнопки:** Не нужно открывать таблицу.
    * Нажал `🚀 Взять в работу` -> Статус в таблице сменился, время зафиксировалось.
    * Нажал `🏁 Завершить` -> Заявка закрыта.
* **Цветовая маркировка:** Скрипт сам красит строки в таблице (Желтый → Синий → Зеленый), чтобы диспетчер визуально контролировал процесс.
* **Логирование:** В отдельную колонку пишется точное время действий (когда взял, когда закончил).
* **Защита от дублей:** Умная проверка не отправит одну и ту же заявку дважды.

## 🛠 Как это работает (Сценарий)

1.  **Диспетчер** создает заявку в Google Таблице: пишет гаражный номер автобуса, суть поломки и ставит статус `новая`.
2.  **Инженер** получает пуш в Telegram:
    > 🚗 **Новая заявка**
    > 🏷 Гаражный: 1054
    > 💬 Коммент: Не работает валидатор
3.  Инженер жмет кнопку **[Взять в работу]**.
    * В таблице статус меняется на `в работе`.
    * Строка окрашивается в синий.
    * Диспетчер видит, что заявка принята.
4.  После ремонта инженер жмет **[Завершить]**.
    * Статус меняется на `завершено`.
    * Строка зеленеет.
    * Кнопки в чате пропадают.

## 🚀 Установка и Настройка

Вам не нужны серверы или платный хостинг. Всё работает на базе Google Apps Script.

### Шаг 1. Подготовка Google Таблицы
1.  Создайте новую Google Таблицу.
2.  Назовите лист **"Заявки"**.
3.  Настройте колонки (порядок важен, либо поменяйте его в `CONFIG` в коде):
    * **A (1):** Гаражный номер / ID
    * **B (2):** Комментарий / Задача
    * **C (3):** Статус (Здесь вы будете писать "новая")
    * **D (4):** Любые доп. данные
    * **E (5):** Лог бота (Оставьте пустой, сюда бот пишет время)

### Шаг 2. Создание бота
1.  Напишите в Telegram "папе всех ботов" - [@BotFather](https://t.me/BotFather).
2.  Используйте команду `/newbot`, дайте имя и юзернейм.
3.  Получите **API Token** (он выглядит как `123456:ABC-DEF...`). Скопируйте его.

### Шаг 3. Установка скрипта
1.  В вашей Таблице нажмите: `Расширения` > `Apps Script`.
2.  Скопируйте код из файла `code.js` в этом репозитории и вставьте в редактор.
3.  **Важно:** В начале кода есть объект `CONFIG`. Проверьте, что названия колонок и листа совпадают с вашими.

### Шаг 4. Деплой (Самое важное!)
Чтобы кнопки работали, скрипт должен быть опубликован как веб-приложение.
1.  Нажмите синюю кнопку **Начать развертывание (Deploy)** > **Новое развертывание**.
2.  Выберите тип: ⚙️ **Веб-приложение (Web App)**.
3.  Заполните поля:
    * *Описание:* Версия 1
    * *Запуск от имени:* **Меня (Me)**
    * *У кого есть доступ:* **Все (Anyone)**. (Это обязательно, иначе Telegram не сможет "достучаться" до скрипта).
4.  Нажмите "Начать". Скопируйте полученный **Web App URL**.

### Шаг 5. Первый запуск (Привязка)
1.  В редакторе кода найдите функцию `setupBot` (в самом низу).
2.  Вставьте внутрь функции свои данные:
    ```javascript
    const token = "YOUR_BOT_TOKEN";
    const chatId = "YOUR_CHAT_ID"; // Можно узнать у бота @userinfobot
    const webAppUrl = "YOUR_WEB_APP_URL";
    ```
3.  Запустите функцию `setupBot` **один раз** вручную (кнопка "Выполнить" ▶️ на панели сверху).
4.  *Совет:* После успешного запуска удалите токен и ID из кода для безопасности. Скрипт уже запомнил их в скрытых настройках.

### Шаг 6. Настройка триггера
Чтобы бот сам следил за таблицей:
1.  В меню слева выберите **Триггеры** (иконка будильника).
2.  Нажмите **+ Добавление триггера**.
3.  Настройки:
    * Функция: `processEdit`
    * Источник: `Из таблицы`
    * Тип события: `При редактировании`
4.  Сохраните.
